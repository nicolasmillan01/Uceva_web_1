# Uceva_web_1

Repositorio de talleres de la asignatura **Programación en Ambiente Web I**.

## Autor

Nicolas Millan Rodriguez - 230222012

## Estructura del proyecto

```
Uceva_web_1/
├── HTML/          # Taller de HTML (10 ejercicios)
│   ├── ejercicio-1.html
│   ├── ejercicio-2.html
│   └── ...
├── CSS/           # Taller de CSS (10 ejercicios)
│   ├── ejercicio-1/
│   │   ├── index.html
│   │   └── styles.css
│   └── ...
├── Corte I/
├── Corte II/
└── Corte III/
```

## Contenido

- **HTML**: ejercicios de estructura básica, texto y formato, listas,
  enlaces e imágenes, tablas, formularios, HTML semántico, figuras y
  citas, e información desplegable.
- **CSS**: ejercicios de selectores, colores y fondos, tipografía,
  box model, display, flexbox, grid, responsive design,
  posicionamiento y pseudoclases.

## Tecnologías

- HTML5
- CSS3
