Conclusión

block ocupa todo el ancho disponible y siempre empieza en una nueva línea. inline solo ocupa el espacio de su contenido y no permite definir ancho/alto. inline-block se comporta como inline pero sí permite ancho, alto y márgenes. none elimina el elemento visualmente y del flujo del documento.
