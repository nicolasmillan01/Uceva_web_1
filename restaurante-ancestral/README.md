# Ancestral Cocktails — Sitio web

Sitio web de una sola temática (restaurante / menú gastronómico) desarrollado con HTML5 semántico, CSS propio y la librería Pico CSS, como taller integrador de los módulos de HTML y CSS.

## Estructura del proyecto

```
restaurante-ancestral/
├── index.html        Página de inicio
├── menu.html          Carta completa (cócteles, sin alcohol, para acompañar)
├── nosotros.html      Historia y equipo
├── contacto.html      Ubicación, horario y formulario de reserva
├── css/
│   ├── pico.min.css   Librería Pico CSS (v2)
│   └── styles.css     Estilos propios: paleta, tipografía y componentes
└── README.md
```

## Tecnologías

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (variables personalizadas sobre Pico CSS)
- [Pico CSS](https://picocss.com/) v2 como base de estilos

## Cómo verlo

Abrir `index.html` en el navegador, o servir la carpeta con cualquier servidor estático:

```
npx serve .
```
